# ICPC/OI Algorithm Template Collection

**My personal competitive programming codebook — shared publicly in the hope it helps others.**

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![C++17/20](https://img.shields.io/badge/C%2B%2B-17%2F20-00599C.svg?logo=c%2B%2B)](https://isocpp.org/)

## About

This is my personal collection of algorithm templates accumulated through competitive programming practice, covering data structures, graph theory, mathematics, strings, dynamic programming, computational geometry, network flows, and advanced techniques.

It's still a work in progress — **feedback, bug reports, and pull requests are all welcome. Let's learn together.**

## Features

- **10+ chapters** covering major competitive programming domains
- **~10,000 lines** of C++ templates, referenced against KACTL and jiangly
- **Complexity cheat sheets** for every algorithm
- **Bilingual comments** (Chinese + English)
- **Copy-paste ready** — each code block compiles independently

## Quick Start

```bash
git clone https://github.com/sixtdreanight/algorithm-templates.git
cd algorithm-templates

# Browse templates
cat algorithm-notebook-cn.md

# Verify compilation
make verify
```
